# Welcome to my website about one of the UNs sustainable development goals!
### Installation

Install the dependencies:

```bash
npm install
```

### Development

- You must start a development server for both the front and back end.
- Start the development server with HMR:

```bash
npm run dev
```

Your application will be available at `http://localhost:5173`.

## Information if you want to further develop the application
#### Folder structure: 
- my-react-router-app is the front end of the site.
- C22a-fullstack-backend is the backend of the site.
#### Components
- NavBar.tsx - For the title and image.
- textbox.tsx - For all text boxes on the site.
- requests.ts - Fetching text data from the server.
- home.tsx - The core page of the website.
#### Helpers
- text.ts | Contains all English and Spanish text

#### Place components and hooks in their respective folders.

## Dependencies
- [Ant design for button styling](https://ant.design/)
